## Descripción

Script en PowerShell (`grupo1.ps1`) que:

1. Obtiene la lista de usuarios locales con `Get-LocalUser` y la guarda en una variable.
2. Pide al usuario un número entero como cantidad límite de referencia.
3. Evalúa con operadores (`-gt`, `-lt`, `-and`) si la cantidad de usuarios es mayor al número ingresado y menor a 10.
4. Muestra un mensaje según se cumpla o no la condición (`if / else`).
5. Cierra mostrando la versión de PowerShell del entorno.

## Ejecución

```powershell
.\grupo1.ps1
```
